# Internal Postmortem Program

A governance-ready program toolkit for turning severe incidents and escalations into evidence-based learning, corrective action, and repeat-risk reduction.

## Why this exists

Major incidents often end with restoration but not durable learning. This package provides the operating model, templates, and cadence needed to synthesize incident evidence, separate root cause from contributing factors, and manage corrective actions through validation.

## Primary users

Executive escalation leaders, incident commanders, support engineering managers, customer success leaders, problem managers, and governance reviewers.

## Outcomes

Consistent postmortem quality, faster executive alignment, stronger corrective action ownership, and a repeatable path from incident evidence to organizational learning.

## Operating cadence

Weekly action review, monthly theme review, and quarterly governance readout.

## How to use

1. Start with docs/operating-model.md to understand ownership and expected outcomes.
2. Use docs/runbook.md during execution.
3. Copy the templates into the active incident, review, or program workspace.
4. Review metrics monthly and update templates as lessons are learned.

## Governance principles

- Evidence before opinion.
- Clear ownership before broad escalation.
- Time-boxed decisions with explicit tradeoffs.
- Corrective actions that are testable, owned, and reviewed.
- Executive communication that distinguishes facts, hypotheses, risks, and asks.
